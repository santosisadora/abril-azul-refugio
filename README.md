# Abril Azul: Refúgio Sensorial 🧩✨

Hub de Realidade Imersiva (WebAR) voltado para adultos em busca de diagnóstico de autismo. Um "Quarto Seguro" virtual com informações curadas, validação e experiências sensoriais.

## 🚀 Como Testar (Versão Alpha)

1. Clone o repositório:
   ```bash
   git clone https://github.com/santosisadora/abril-azul-refugio.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse o URL gerado (ex: `http://localhost:5173`) no seu navegador (Chrome no desktop ou via QR Code no celular).

## 🧩 Elementos do Quarto (Interativos)

- **O Espelho**: Conceitos de camuflagem social (Masking).
- **A Estante**: Links e fontes de informação curadas.
- **O Fone de Ouvido**: Simulação de sensibilidade auditiva.
- **O Laptop**: Triagens para autoavaliação (ex: RAADS-R).
- **Nicho de Coleções**: Explicação sobre Hiperfoco.

## 🛠 Tecnologias

- [A-Frame](https://aframe.io/)
- [MindAR](https://hiukim.github.io/mind-ar-js-doc/)
- [Vite](https://vitejs.dev/)
